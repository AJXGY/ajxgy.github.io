Publications & Patents

Multi-view based network for malware classification
发表：Engineering Applications of Artificial Intelligence, 2026 · 第一作者 · SCI 一区 · IF 8.0（2024 JIF）
SCI Q1 · First author

提出双层多视图恶意软件分类框架，结合 ViT、VGG 与 Bilinear Attention Network，在 Microsoft Big2015 数据集上取得 98.78% accuracy 和 98.76% F1-score。

DOI PDF
Plant-Scale Biogas Production Based on Integrating of CEEMDAN Decomposition with PSO Optimized Multilayer Perceptron Neural Network
发表：Fermentation, 2024 · 共同第一作者 · SCI · IF 3.3（2024 JIF）
Co-first author

构建 CEE-PMLP 沼气产量预测模型，结合 CEEMDAN、PSO 与 MLP，对大型厌氧消化工程产气序列进行预测，R² 达到 0.98。
